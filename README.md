# Newsletter

Uma landing page de newsletter responsiva desenvolvida com HTML, CSS e JavaScript.

## Funcionalidades

- 📱 Layout responsivo
- 🌙 Tema Light/Dark
- 📧 Formulário de inscrição
- 📅 Ano atualizado automaticamente no rodapé

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Objetivo

Praticar conceitos de desenvolvimento Front-end, como responsividade, manipulação do DOM e criação de interfaces modernas.
